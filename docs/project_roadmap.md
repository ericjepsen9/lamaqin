## Chat 拆分策略

### 为什么要拆?

- 当前 chat 已经接近 context 上限
- 不同阶段需要不同信息焦点(避免无关上下文干扰)
- Project 里的 5 个 md 是**单一事实源**,新 chat 通过 `project_knowledge_search` 自动接上

### 拆分原则

| Chat # | 名称 | 阶段 | 主要交付 |
