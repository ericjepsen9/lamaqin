## 1.2 组织层级(最终决定 2026-05-22)

```
学会(整个佛学会 = 所有师兄)        ← "全会" 指这一层
  └ 班(加行 / 净土 / 入行 / 学经 / 基础 / 中观 / 密法…)
        · 科系标签(以后加):预科系 / 正科
  └ 届 / 年次(22届 / 23届…;统一用「届」不用「级」)
```

| 术语 | = | 含义 |
|---|---|---|
| **学会 / 全会** | 所有师兄 | 最高层,跨班跨届。"每周回向"全会层 = 这一层 |
| **班** | 核心单位 | 如"加行班";具体学习单位 = 班 × 届(如"22届加行班") |
| **科系标签** | 班的属性(以后加) | 预科系 / 正科;**不单独建层**(原则 2 减法),需筛选时按标签过滤 |
| **届 / 年次** | COHORT 的年份 | 用「**届**」(22届),**不用"级"** |

⚠️ **重要纠正**:原 PRD §2 把"正科"当成跟加行平级的**专业(6 专业之一)**。**实际**:正科是**科系标签**(下辖中观班/密法班),不是一个班。预科系下辖 基础/加行/净土/入行/学经。
⚠️ **"班"歧义**:口语"加行班"指内容(加行);系统里一个具体班 = 班 × 届。auto 愿绑具体班(届);custom 愿不绑。
> **待办(应用时)**:PRD §2 组织层级措辞据此调整;PRD line 2126 "19级班" → "19届班";"级"全局统一为"届"。

## 1.3 课程内容(course / 节 / 讲解 三层 · 2026-05-26 brainstorm 固化)

> **核心划分**:讲解归「闻」(课程),观修归「修」(修持项目,见 1.5)。两者分开。
> **三层模型(关键,勿混)**:course(教典本身,无固有节)→ 权威节号轴(由上师讲解定义)→ 各讲者讲解(挂靠权威轴的听课资源)。

```
course = 一部经/论/上师开示(教典本身,华智仁波切《前行》等;★无固有节数★)
  · author 造者:论→造论者(华智/麦彭);经→"佛经";上师开示→留空
  │
  ├─ 权威节号轴 = 上师讲解定义(《前行》=144 节) → course_lessons(lesson_number 1..N)
  │     └ 思考题/听课/讲考/共修/师兄进度 全部挂此轴(lesson_id);全班唯一坐标
  │
  └─ 各讲者讲解(挂靠权威节的听课资源) → lesson_resources
        · 上师讲解 144 → 逐节 1:1
        · 智诚堪布 144 → 逐节 1:1 对齐上师节号
        · 圆函堪姆 135 → 合讲(如22-23合一);该录音在节22、节23各挂一条(走甲·允许冗余)
```

| 术语 | = 数据 | 含义 |
|---|---|---|
| **course**(经/论/上师开示) | `courses` | 一部完整教典,**本身无节**。"经/论/开示"是性质,不单独存字段 |
| **造者 / author** | `courses.author` | 论→造论者(华智/麦彭);经→"佛经";上师开示→留空。**≠讲者** |
| **节(最小单位)** | `course_lessons`(lesson_number) | ★由上师讲解定义的权威节号★。**"课"字退役**(歧义),一律称"节" |
| **权威节号轴** | course_lessons 1..N | 全班唯一进度坐标;思考题/讲考/共修/考试范围全按此(如前行 1-144) |
| **讲解 / 讲者版本** | `lesson_resources`(挂节) | 某讲者讲某节的 video/audio/notes;一节可挂多位讲者;**讲者节数可不同,都映射回权威轴** |
| **讲者** | lesson_resources.讲者名 | 上师(索达吉堪布)/智诚堪布/圆函堪姆…;尊称写名字里,不分层级 |
| **lesson_id** | course_lessons 主键 | 听/思/讲/共修都关联同一 lesson_id(原则 11),可跳着做 |

⚠️ **权威节号轴 = 闻思数据地基**(详见 principles 原则 11 展开):上师讲解定义节号,**法师辅导/思考题/法本/讲考全部对齐挂靠此轴,不另起编号**。讲者节数可异(圆函135≠上师144),但都映射回权威节。
⚠️ 课程内容**全局固定**,不绑届/班(原则 13)。"本周第 N 节"由 `get_current_lesson_number()` 算(按权威轴)。
⚠️ **班 / 届 / course 关系**:班=专业(加行班,读 N 部 course);届=群体("我们班"=22届加行);course 挂"班"不挂"届"(22届/23届加行读同一批 course)。
⚠️ schema:course_lessons 存权威节;lesson_resources 装多讲者(决定 #185);圆函式合讲走"同录音挂多节"(走甲,不加节区间字段)。
⚠️ 限制性课程(大学演讲18册):独立于专业course,2026-05-26 起【册→文章两层】(self_study_books 18册 → self_study_articles 70篇),师兄**按文章打卡**(self_study_records 挂 article_id)。不挂权威节号轴、不考试、不限时。
> ⚠️ **防歧义(2026-06-02)**:"限制性" = **限定必读**,**≠ 密法受限**。① 内容**公开可传播**(决定 #188:只放可公开教言,不涉密法窍诀),不走密法 0 痕迹红线。② DB 实名 = `self_study_books` / `self_study_articles`;**"restricted" 仅历史种子文件名** `_源料/seed_restricted_books_18_2026-05-26.sql`,**英文勿用 restricted 命名任何新表/列/视图**,以免与密法访问控制(`is_tantric` / `tantric_access_grants`)混淆。

# 第三部分 · 易混词辨析(重点)
═══════════════════════════════════════════

**「共修 / 回向」相关,务必分清:**

| 词 | 指什么 | 在哪 |
|---|---|---|
| **共修(出勤)** | 班级群体活动,group_attend,93 次硬指标。**核心,保留** | 「当日」/ 主麦 A8 |
| **集体回向** | 各自修 → 总和一起回向(法会+每周),只看总和 | 「同修」 |
| **约修** | 临时发起的一起修,他人加入 | 「同修」 |
| **功德回向** | **个人**累计功德(回向视角) | 「末学」 |

→ 已删早先"集体共修"叫法(不准 + 与"共修出勤"撞车)。集体的叫「集体回向」,个人的叫「功德回向」。

**「修行」vs「修持打卡」:**
- 修行(S9)= 看/调我的功课(改节奏、暂停)— 计划
- 修持打卡(S10)= 记录今天修了多少 — 执行

**「当日修量 / 总修量 / 集体回向」三种可见性(勿混,#203):**
- **当日修量(人气)** = 在场感;v1.0 匿名计数,v1.5+ 师兄自愿具名(法名+**当日**量,会清零的小数字 → 随喜非排名)
- **总修量(个人累计)** = 仅师兄本人可见(功德回向);**向他人暴露 = 否决**(累计是排名燃料,违无缘)
- **集体回向** = 一个**总和数字**,全班/全会可见但**不显个人**(#182)
- 红线辨析:具名"互看他人累计/进度" = **永久否决**(#193);区别于"当日自愿具名"(#203)——后者方向是师兄主动亮、范围仅当日、性质是随喜,三点缺一即滑回被否决的互看

**「总累计目标」vs「功德回向」(关键,勿混):**
- 总累计目标 = "还要修满 X 才达标" → **隐藏**(避免压力,场景 2/6)
- 功德回向 = "已积累 X,可回向众生" → **展示**(正向,#179)

**「班」歧义**:口语指内容(加行);系统里 = 班 × 届。详见 1.2。

## 4.1 主语省略规则

- **个人/自己的东西** → 默认**省略主语**(App 本就是"我/末学"在用,"我的"冗余,且呼应「末学」自谦):「修行」「功德回向」「日记」
- **集体的东西** → **必须写明主语/范围**(避免误以为个人):「集体回向」「班级公告」「每周回向(班级层/全会层)」

## 4.2 白话化原则

- 显示名用师兄熟悉的修行者语言,不用开发视角技术词
- 数据库技术名(如 user_practice_vows)**不改**,仅改 UI 显示
- 例:愿管理 → 修行;个人统计 → 功德回向

## 4.3 自谦称

- Tab「末学」用自谦称(导航处得体);子功能名不必都加"末学的…"(拗口),按主语省略规则直接用「修行」「功德回向」
