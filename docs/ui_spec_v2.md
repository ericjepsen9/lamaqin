## 2 · 字体
- **衬线 Noto Serif SC / Songti SC**(`font-serif`):标题、法本讲记正文、卡片标题、tab 文字、书名(三殊胜语感)。
- 无衬线:正文、辅助说明、数字/统计。

## 3 · 图标 ——⭐ 线性图标(2026-06-19 定)
- **统一采用线性(outline)图标 = Lucide RN**(技术栈锁定);**不用填充/拟物/多色图标**。
- 线宽统一(Lucide 默认 stroke 2);尺寸按层级 16 / 18 / 20 / 22 / 24。
- emoji 仅作**占位封面**(书封 📖/🪷),非功能图标;接 `cover_image_url` 后用真封面替换。

## 4 · 首页覆盖层(画报之上)
- **顶部覆盖图标 = 圆形磨砂玻璃 + 白图标**:左上 = **我的头像**(User·→/me·决策158);右上 = **通知铃** + crimson 红点。
- 日期 = 白色衬线 + 轻阴影;藏历 = 白色小字 + 轻阴影。
- **去**右上日历;右上**只留通知**。
- 中部纯画报:无诗句、无 streak、无签到。

## 5 · 导航 / Tab
- **底部 4-Tab**(决策158:首页/闻思/修持/班级;我的移首页左上头像):透明、纯文字、激活 saffron + 短下划线(浮在画报上不挡图)。第4个 tab「班级」对纯自学用户动态变「自学」(决策144)。
- **drill-in 页**:左上 `ChevronLeft` 返回;课程详情顶部右 `⋯`(MoreHorizontal)。
- **学修流(本课)**:顶部步骤进度条(闻·辅·答·修,可点跳)+「目录」按钮;**底部 ≤2 按钮**(上一步/下一步 或 单一主操作)——不堆按钮。

## 6 · 卡片 / 按钮 / 弹窗
- **卡片**:白底 + `1px` border `rgba(43,34,24,.08)` + 圆角 14–18;首页用磨砂玻璃卡。
- **按钮(决策 A–C·2026-06-25 PM 拍板;管理端已扫齐)**:
  - **主按钮**:saffron `#e07856` 实心 + 白字 + **胶囊形**(`borderRadius 9999`)。
  - **次按钮**(编辑/上传等次要操作):浅橙 `#fbe5da` 底 + 深橙 `#c55f3d` 字、无描边、胶囊形(「软橙药丸」)。
  - **否定按钮**(取消/拒绝):白底 `#fff` + 灰描边 `#ddd3ca` + 深橙 `#c55f3d` 字、胶囊形。
  - **危险按钮**(删除/撤销权限):浅绛红 `#fbedea` 底 + 绛红 `#a13c2e` 描边/字;点后二次确认。当前代码暂无此类按钮,先立规。
  - **文字链接**:深橙字、无底无边。圆角档位:标签 7 / 输入 10 / 卡片 16–18 / 按钮·chip·头像 胶囊。
- **弹窗**:居中 dialog(cream 圆角 18)/ 底部 sheet(圆角 20);遮罩 `rgba(0,0,0,.35–.4)`。
- **进度条**:轨 `rgba(43,34,24,.10)` + saffron 填充。

## 7 · 克制红线(视觉层)
- **师兄端无状态色**:`current_status`/at_risk/falling_behind 等**仅管理端**;师兄端 sage 绿只表"进度/已学",不做预警红黄。
- **不排名、不催促**;集体只出总和、不具名(#193)。
- **进度本人可见**(决策014/145):本人可看自己愿的总目标+进度。
- **密法 0 痕迹**:无密法课程/字段/门禁。

## 9 · 管理端共享组件库(2026-06-25 建立·代码事实源 = `components/ui/admin-kit.tsx`)
> 痛点:此前各页 `StatusBadge`/卡片/按钮/头像/表格 **copy-paste**(StatusBadge 曾 5 处副本、徽章样式 40 处重复),改一页其他页不动,难维护。**本节确立:管理端所有页面统一引用 admin-kit,禁止再各页自定义这些基础元素**;改组件一处,全后台跟着变(与 `lib/theme.ts` 色值源配套——色值改 theme、组件改 admin-kit)。
> ⚠️ 本节为 docs 只读副本的就地登记;回规划中枢同源订正后再覆盖同步(防分叉)。

| 组件 | 用途 | 关键 props |
|---|---|---|
| `Badge` | 状态/分类徽章(浅底深字) | `tone`: saffron/sage/gold/crimson/neutral/violet |
| `Avatar` | 首字圆头像(saffron) | `name`、`size`(默 42) |
| `Card` | 白底圆角卡(可点/可选中) | `onPress?`、`selected?` |
| `SectionCard` | 带标题白卡(含内距) | `title?` |
| `SectionHeader` | 区块标题 + "查看全部→" | `title`、`moreLabel?`、`onMore?` |
| `StatCard` | 统计块 | `variant`: bar(左色条) / tint(柔色底)、`accent` |
| `AdminButton` | 按钮 5 态 | `variant`: primary/secondary/negative/confirm/danger、`size`、`icon?` |
| `SearchBar` | 搜索框 | `value`、`onChangeText` |
| `FilterChips` | 筛选标签组 | `items`、`value`、`onChange` |
| `Table`/`TableRow` | 宽屏表格(自动表头) | `columns`、`TableRow.last?` |
| `Divider`/`EmptyState` | 分隔线 / 空态文案 | — |

**色调映射约定**(各页状态枚举不同,统一映射到 tone,视觉才一致):
绿/在读/正常/已完成→`sage`;橙/待审/提醒/落后→`saffron`;金/偏滞/等第→`gold`;红/危险/否决→`crimson`;灰/中性/已离→`neutral`;紫/密法→`violet`。

**按钮变体约定**(对齐 §6):主操作(新建/批准/保存,实心橙)→`primary`;次要(编辑/上传)→`secondary`;取消/拒绝(白底灰边)→`negative`;正向确认(确认毕业,sage 绿)→`confirm`;删除/撤销(绛红)→`danger`。

**弹窗**(2026-06-25 已统一):`AdminModal`(居中白卡 + 顶部 X 关闭 + 遮罩 rgba .4 + fade)/ `ModalField`(标签+输入,multiline 多行)/ `ModalActions`(按钮行)/ `ModalFootnote`(脚注)。遮罩点击默认关闭,**含表单输入的弹窗传 `dismissOnOverlay={false}` 防写一半误关丢数据**。全部 6 个弹窗(courses 新建 / advancement 确认 / calendar×3 / events 编辑)已接入。

**保留本地**(只此一处、非通用):学员 5 维快照条、班级满班进度条、关怀时间线、弹窗内的 Switch 开关 / 分段选择器(SegBtn)/ 上传占位。分段选择器统一(`SegmentedControl`)是**待办下一步**。
