## 一、注册与身份

### 1.1 登录门槛分层（决策037）

| 状态 | 可做什么 |
|---|---|
| 未登录 | 浏览课程内容（只读），不能打卡/答题/发愿 |
| 最简注册（邮箱验证 + 昵称） | 可使用全部自学功能 |
| 完善全部资料（法名/姓名/手机号等） | 可申请加入班级 |

触发方式：用户触碰需要写入数据库的操作时弹出登录提示，不强制提前登录。

### 1.2 双层身份控制（决策006/007）

**Platform 层**：`profiles.enrollment`
- `informal` = 未完善资料，看不到班级入口
- `formal` = 已完善全部资料，可进入班级列表

升级时机：完善全部资料提交后自动升为 formal。

**Class 层**：`class_members.member_role`
- `auditor`（旁听）= 入班默认身份
- `formal`（正式成员）= 辅导员及以上手动转正，不可降级

### 1.3 入口流程（决策003）

```
打开 App
  ↓
首屏（未登录可看）：选择模式
  ├─ 自学  → 最简注册 → 科系选择（可跳过，有独立选择页）→ 开始使用
  └─ 班级  → 完善全部资料 → 选班 → 以旁听身份入班
```

### 1.4 自学科系选择（决策038）

- 注册时提供科系选择，**可跳过**
- 跳过后有独立选择页，随时可进入选择
- 未选科系时首页显示引导态，不显示课程任务
- 选定科系当天作为 `start_date`，开始计算本周进度

## 二、旁听机制

### 2.1 旁听定义（决策030）

旁听与正式成员唯一区别：**不参与毕业和升学流程**。其余完全一致：

- ✅ 听课、答思考题、修持打卡、共修出勤签到、讲考
- ✅ 看班级公告 / 共修 Zoom 链接
- ✅ 建 auto 愿（入班当天起修）
- ✅ 进入关怀名单和状态机统计

### 2.2 课程进度（决策039）

师兄加入班级后，课程进度**按班级时间轴显示**（显示当前班级进度第N课）。历史课可补录，补录即时生效。

### 2.3 记录连续性（决策027/028/029/031）

| 场景 | 规则 |
|---|---|
| 旁听 → 转正 | 旁听期所有记录即时生效，转正后全部追溯计入毕业/升学统计 |
| 退出 → 重进同班 | 所有历史记录保留生效，auto 愿状态接续不重建 |
| 跨班 | A 班记录不带入 B 班（唯一保留的隔离规则） |

### 2.4 转正操作（决策006/040）

- 辅导员及以上可操作；弹窗含原因（可选填）+ 确认
- 不可逆：正式成员不能降回旁听，退出只能离班
- 转正后 App 内通知师兄「您已成为正式成员」

## 三、愿（发愿系统）

### 3.1 模板归属（决策012）

模板挂在**课程（program）**上，班级（cohort）可覆盖：

```
查找逻辑：先找 cohort 覆盖版 → 无则 fallback program 默认
```

自学师兄选课后直接按 program 默认模板建 auto 愿。

### 3.2 auto 愿建立时机（决策010）

入班即建，起修日 = 入班当天（旁听也建，不等转正）。

### 3.3 总目标可见（决策014）

师兄可看到**本人**每条愿的总目标 + 当前累计进度（如 87,000 / 100,000）。

- 原"隐藏总累计目标"设计废除
- 不变红线：仅本人可见，向他人暴露进度永久否决（#193）

### 3.4 达标处理（决策013）

累计达到目标时 App 提示，师兄可选择：

- 手动确认结愿 → 状态变 `completed`，停止打卡
- 不确认 → 维持 `active`，可继续超额打卡到截止日

### 3.5 模板修改同步（决策015/016）

管理员改模板时可选「是否同步到已有愿」：

- 同步范围：`active` + `paused` 且累计未达标的愿
- 保留不覆盖：师兄自改的节奏字段（起修日、每日/每周目标）
- 已达标 / `completed` / `abandoned` / 过期的愿不受影响

### 3.6 宽限截止日（决策034）

辅导员可宽限**本班**师兄的愿截止日；admin 可操作所有班。操作写 audit_logs，改后状态机重算。

### 3.7 状态机阈值（决策032）

| 状态 | 触发条件 |
|---|---|
| `falling_behind` | 连续断签 ≥ 7 天 |
| `at_risk` | 按当前进度，数学上截止日前无法完成剩余量 |

每日制愿 + 终生愿：只走断签判定，无 `at_risk`。
入行观修（按周目标）：本周已过 ≥4 天且本周座次=0 → falling_behind。

## 四、共修与出勤

### 4.1 出勤录入（决策020）

两条通道，取消师兄在 App 内自填：

| 通道 | 说明 |
|---|---|
| 通道一 | 辅导员 / admin 后台直接填写，直接生效，无需审核 |
| 通道二 | 共修时发 Zoom 签到链接，师兄点击选自己头像，待辅导员审核 |

### 4.2 签到链接（决策022/023）

- 辅导员手动生成，默认 60 分钟有效窗（可调）
- 师兄免登录点链接，页面显示本班**全体成员**（旁听 + 正式）头像
- 点自己头像 = 签到（待审核）；已签头像置灰防重复

### 4.3 签到审核（决策043）

先全部确认，再单独剔除异常（代签/误签）；手动补填缺席师兄走通道一。

### 4.4 师兄端出勤表（决策021）

只读展示，师兄不能修改；事后纠错走辅导员/admin。

### 4.5 审核语义（决策011）

`is_confirmed` = 辅导员已阅/已关怀（非数据锁定）。师兄修改已确认记录后自动重置为待审。自学师兄默认 `true`。

## 五、答题体系

### 5.1 题型（决策025）

支持 14 种题型（对齐觉学），包括选择、判断、填空等结构化题型 + 开放问答。

### 5.2 答案策略（决策036）

**所有题型一律不显示参考答案**。参考答案字段保留供辅导员批阅，不向师兄端透出。师兄提交后只显示「已提交」，可无限修改答案。

## 六、修学计数规则

### 6.1 听课（决策047）

记录多次，每次听都写一条记录。闻思圆满判定以「≥1遍」为准（有任意一条记录即满足）。

### 6.2 加行观修座次（原设计 + 决策048）

- ≥30分钟 = 1座；无0.5座
- 碎片池（<30分钟）：同一修法累计，凑满30分 = 1座，余数清零
- **对师兄显示碎片累计**：「再修X分钟可完成1座」

### 6.3 净土打卡（决策049）

填写实际念佛数量（遍数）；当日累计 ≥ 目标遍数 = 算完成该天；三种念佛号（5000/7500/900遍）入学锁定。

### 6.4 入行观修（决策050）

- 打卡1次 = 1座，**时长不限**（时长选填仅留档）
- 每周目标 ≥3座，自然周独立不跨周累计
- 无碎片池

### 6.5 学经固定功课（决策051）

心经每日目标遍数（1-9遍范围）通过 auto 愿模板在后台配置，cohort 可覆盖，师兄可自调节奏。

### 6.6 学经自选经（决策052/053）

- 可选经典列表由 admin 配置（以七经为基础，可增减）
- 师兄从列表选择，不能自由输入
- 抄经/拜经均以遍数计算（整本=1遍）

### 6.7 打卡通用规则

| 专业 | 单位 | 目标周期 |
|---|---|---|
| 加行观修 | 时长 → 系统算座次 | 全修法累计（每法≥3座/≥30min） |
| 加行内加行 | 遍数 | 全期10万/项 |
| 净土 | 遍数 | 每日目标（锁定念佛号） |
| 入行观修 | 打卡次数（1次=1座） | 每周≥3座 |
| 入行心咒 | 遍数 | 每日≥1000遍 |
| 学经固定 | 遍数 | 每日目标（模板设定） |
| 学经自选/抄经/拜经 | 遍数 | 师兄自定 |

## 七、辅导员端

### 7.1 仪表盘（A1屏，决策041）

- 关怀名单（at_risk / falling_behind）
- 本班整体出勤率（本学期累计）
- 本周答题提交人数

### 7.2 学员详情（A3屏，决策042）

闻思进度按周显示（第N周✅/⬜），底层按课存储，展示层聚合。

### 7.3 宽限 due_date（决策034）

辅导员可宽限本班师兄愿截止日；弹窗含新截止日（默认+30天）+ 原因（可选）；写 audit_logs；改后状态机重算。

## 八、关怀机制

### 8.1 关怀名单

旁听者与正式成员完全同等对待，无需标注身份（决策030）。

### 8.2 跟进记录入口（决策033）

双入口，写同一张 `care_followups` 表：

- 关怀名单条目直接记录（快速）
- 学员详情页「跟进记录」tab（深度，可查历史）

### 8.3 爱心师兄权限（决策035/044/045/046）

| 操作 | 爱心师兄 |
|---|---|
| 查看关怀名单 | ✅ |
| 查看全班成员列表 | ✅ |
| 查看师兄全部学修记录 | ✅ 只读 |
| 查看师兄手机号 | ✅ |
| 记录跟进（care_followups） | ✅ |
| 宽限 due_date / 修改任何数据 | ❌ |
