## 2. 决策落地(本次实现所依据 / 明确的口径)
- **决策012**:模板挂专业(`practice_templates.applies_to_programs`);班级发愿**逐「修法」fallback**——
  本班有覆盖(`cohort_recommended_templates`)用覆盖,否则用专业默认。自学按专业默认(无 cohort)。
- **决策010**:非限时 auto 愿起修日 = 入班当天(`class_members.joined_at`)。
- **决策073/086/122**:内加行 = **限时愿**(本次给 `practice_templates` 加 `is_time_limited` 列,
  决策086「从硬编码降为模板数据实例」落地);限时愿:起修 = 开班日 + `starts_offset_days`(梯次)、
  截止 = 起修 + 建班年限(`cohorts.neijiaxing_lock_years`,默认4)、仅 admin 延期 / 过期锁定(锁定走应用层#190)。
- **发愿时机口径(本次明确,2026-06-28)**:**改为应用层显式调用,不埋 DB 触发器**
  (对齐项目「逻辑别埋触发器」原则 + 避免触发器吞异常导致「入班却悄悄没愿」)。
- **自学限时年限**:自学无班级配置,暂默认 4 年(边缘场景,待 PM 复核)。
