# 觉学 · 业务术语表 Glossary

> 状态：进行中（2026-05-31 创建）
> 用途：统一业务术语定义，防同词异义。引用决策见 `decisions/05-decision-log`（D 编号）、`decisions/06`（能力编号）、`decisions/08`（DR 编号）。

---

## 一、阶段与专业

| 术语 | 定义 | 来源 |
|---|---|---|
| 阶段（preke / zhengke）| 预科 / 正科，系统层固定两级，不可新增第三级 | D2 |
| 专业 | 阶段下的修学方向（加行/净土/入行论/学经/密法…），**数据驱动可配置** | D3 |
| 届 | 同一专业的不同期数（19/20/21…），由 subject_admin 管所有届 | D8/P5 |
| 班级（Class）| 某专业某届的具体班；出勤/报数/成绩的归属容器；只归档不删除 | D19 |
| 主修 | 学员指定的默认专业，**仅 UI 偏好**，不影响任何业务规则 | D10 |

## 二、闻思与观修

| 术语 | 定义 | 来源 |
|---|---|---|
| 闻思 | 听（音/视频任一）+ 看（阅读）+ 答题，三者构成圆满判定 | 能力 3 / DR-92 |
| 圆满 | 课时闻思完成判定（听≥1 + 看≥1 + 答题）| 能力 3 |
| 观修（看视频）| 看引导视频/PPT 学习如何修；MeditationSession 记进度 + 完成排行 | DR-111 |
| 观修（打坐统计）| 92 修法逐一打坐，记座数 + 时长，升学硬条件 | 能力 4 |
| 座 | 一次打坐，**单座 ≥30 分钟**才计；座数=COUNT、时长=SUM 双维度独立 | DR-91 |
| courseType | 课程教学阶段：entry/formal/restricted，与 category 正交 | DR-93 |

## 三、实修与报数

| 术语 | 定义 | 来源 |
|---|---|---|
| 内加行 | 6 项各 10 万的累计型实修；含法王祈祷文独立计数（prayerCount）| 能力 6 / DR-95 |
| 累计型实修（D14a）| 毕业累计目标（如观音心咒 10 万），跨专业**共享豁免** | D14a |
| 日常型实修（D14b）| 每日功课（净土 5000/入行论 1000），跨专业**独立不豁免** | D14b |
| 金刚萨埵代顶礼 | 身体原因可申 200 万心咒代 10 万顶礼，走能力 5 代行留痕 | DR-94 |
| 共修 | 班级集体修持；ClassSession 排课 + ClassSessionSchedule 课表模板 | 能力 8 |
| 出勤 | 共修签到，token 生成时刻为基准 + checkinGraceMinutes 宽限 | DR-89 |
| 报数 | 学期节点的数据快照（SemesterSnapshot，冻结不可改）| 能力 9 / DR-83 |
| 虚报忏悔 | 报数不实须先走忏悔流程（ReportConfession）再处理 | 能力 9 / DR-84 |

## 四、升学与传承

| 术语 | 定义 | 来源 |
|---|---|---|
| 升学 | 预科→正科，硬条件不放宽（闻思+92修法+6项10万+顶礼+考试+灌顶）| D13 |
| 升学条件配置 | ProgramAdvancementConfig，6 类 conditionType，params Json 表达复杂条件 | DR-97 |
| 升学预检 | AdvancementCheck，逐条判定 + 可豁免（checkResults Json）| DR-85 |
| 年龄豁免 | ≥60 岁获免考**资格**（非自动），走能力 5 代行确认 | DR-70/100 |
| 传承 / 灌顶 | TransmissionRecord（sourceType=empowerment 表达灌顶），升密法前提 | D4 / DR-44 |

## 五、角色与治理

| 术语 | 定义 | 来源 |
|---|---|---|
| 4 角色 | class_tutor(1)/class_admin(2)/subject_admin(3)/super_admin(99)| 02 文档 |
| 权限继承 | 上级自动拥有下级全部权限（等级数值比较）| D7 |
| 作用域 | 角色生效范围：class_id（班级角色）/ major_id（学科）/ 全局 | D8 |
| 一人多角色 | 一个用户可多条 UserRoleAssignment，身份不互斥 | D8 |
| 代行（proxy action）| class_admin+ 对学员档案的豁免/替代/调整/修正，**必须留痕双方可见** | D17 |
| 留痕 / append-only | 关键事件永久保留、绝不物理删除；UI 按角色差异化展示 | D18 |
| 辅助员 | 配对帮带学员，**不属 4 角色**，独立表 AssistantAssignment + 固定权限集 | DR-82 |
| 特殊身份 | 盲（blind=视障类）/ 聋（deaf=听障类），影响闻思判定路径 | 能力 12 / DR-92 |
| 关怀清单 | CareWatchlistItem，掉队/低出勤触发，partial unique active | 能力 14 |
| 掉队 | CohortLagSnapshot，五维各独立取值（on_track→at_risk），阈值专业配置 | DR-88 |
| 邀请码 | ClassInviteCode，有时效/次数/可撤销（取代旧无时效 joinCode）| D11 / DR-81 |

## 六、文档/方法术语

| 术语 | 定义 |
|---|---|
| 自学模式 | 无法跟班的师兄走的个人自学轨道（能力 21，DR-145 转必做）：subject_admin+ 开通、无班级、进度纯完成量、不参与升学/共修/报数/关怀；要升学须先经邀请码入正式班级 |
| 净资产 | 线上已有、不在 1-25 能力内但改造须保留复用的成熟功能（见 03 §5）|
| 实现状态标签 | ✅保留 / 🔧需改 / 🆕待建 / ⏸暂不上线 / ❌去掉（见 03 §1）|
| DR | Decision Record，08 §八的决策记录编号 |
| 一致性检查 | 08 §九「检查轮次」，每次设计变更后跑的核对 |
