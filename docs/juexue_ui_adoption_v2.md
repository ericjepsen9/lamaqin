## 0 · 觉学是什么(必读认知)

觉学**不是一套通用 UI**,而是**一条平行的三殊胜实现线**:
- 同一份上游「大纲/总清单」,**两个团队(两个 Claude)、两套技术栈**做出来的两条三殊胜实现。
- 觉学包里的 `ui规范/docs/09-页面与交互设计.md` 本身就是把觉学平台映射到三殊胜需求的设计稿(引用 `FINAL_DESIGN_SANSUSHENG.md` / `08-merged-design.md` / 大纲 / blind-deaf 豁免 / 内加行 6×10 万 / 报数 / 圆满判定),并有一套与我们 `决策xxx` 平行的 `DR-xxx` 决策日志。
- **技术栈**:觉学 = React 18 + Vite **网页** + Fastify/Prisma 自建后端;我们 = Expo **React Native** + Supabase/RLS。

**核心机制高度趋同**(同源大纲),**分歧**在于两边各自拍的板不同——其中两处撞我们永久红线。

**PM 决定(2026-06-18):觉学为骨架、我们 2.0 红线+设计为约束。**

### ⚠️ 平台落地现实(非功能冲突,但决定"怎么照觉学做")
觉学是 **React 网页**(CSS / div / react-router / Vite);我们是 **Expo RN**。
→ "照觉学做" = **在 RN 技术栈里按觉学的设计/布局/流程重新实现**,**不是**拷贝 `.tsx`。觉学源码作**设计参照**(布局、信息层级、交互态、文案),组件走我们的 NativeWind + RN Reusables。

## 3 · 净结论:采 / 不采清单

### ✅ 采纳觉学(骨架/兼容,RN 重实现)
- **5-Tab 学员导航**:首页 / 闻思 / 修持 / 班级 / 我的(`TAB_NAVIGATION_DESIGN.md`)
- **今日修学卡**(首页全宽卡,整合今日任务+继续入口)
- **藏历**(已决策137:觉学 TibetanDay 数据+月历 UI+UTC+8)
- 页面骨架:圆满判定(听/看/答三勾+盲聋分支)、内加行 6×10万+法王祈祷文进度、报数页+虚报忏悔、关怀清单+5维掉队(管理端)、代行5类+学员可见、传承/灌顶**记录**页、法会发愿+集体回向(只总和)、自学进度页
- quiz UI(**仅我们 7 型**对应的组件)、阅读器(Apple 图书风,沉浸阅读)、笔记壳(dormant)、设置/隐私/个人中心

### ❌ 不采纳(红线/克制/模型冲突)
- 排行榜(`ClassRankingPage`/`ClassPracticeRankingPage`/`ClassMeditationRankingPage`)+ 班级动态具名随喜
- 密法 gating + App 内密法法本(`TantricGroup`/`isTantric`/灌顶解锁正文)
- 邀请码自助入班页(`/join`)+ 无审批门流程
- 5 守卫角色体系 + 辅助员委托(用我们 4 角色)
- 预科/正科 advancement 作为唯一升级路径(用我们旁听/转正+学号);不引入 advanced/disqualified 状态
- 学员自助签到(`/checkin` token 选自己)(用后台录入)
- 觉学多出的 7 个互动题型(multi/sort/match/image/listen/flow/guided/scenario)
- 9 条推送里的催促类(进度落后/未完成任务/迟到)
- 富笔记 LLM 动作 + AI 出题 + AI 助手 RAG(生成式,v1.0 不做)
- 首页 streak 连续天数徽章

### 当前主修上下文(决策144 · 统一"主班 / 主修自学")
- **概念**:App 任何时候有【一个当前主修】,**唯一驱动**首页 4 卡 + 快速计数默认愿 + 第5 tab。两种形态:
  - **在班的人 → 当前主修 = 主班**(`class_members.is_primary`;自学若有=附加轨道,放「闻思」tab,不抢主修);
  - **纯自学的人(无班)→ 当前主修 = 主修自学专业**(`user_self_study_programs`,**需新增 `is_primary`**)。
- **设为主班 / 设为主修 = 同一套 UI**(方案C:班级/自学页内切换器 + 「我的」设置项),按用户类型走不同底层轨道;切换器列"我的班 + 我的自学专业",选一个设为当前主修。权限=本人(限自己 active 轨道)+ admin(决策131/134);写 audit。
- **第5 tab 动态**:在班→「班级」(5区);纯自学→「自学」(自学专业进度/休息周/自学愿)。
- **DB(PM 2026-06-18 同意·待 apply)**:`user_self_study_programs` +`is_primary boolean` + 每人最多一个主修自学的唯一约束 + 镜像 `switch_primary_cohort` 的 `set_primary_self_study_program()` RPC;首个自学专业默认主修。**仅出方案,迁移待 sss/Eric apply 协调时写。**
- **上游依赖**:自学"本周第N课/揭示下一节"进度推进仍未决(CLAUDE.md §5)→ 自学卡片**进度文案**待该问题定;**主修选择机制 + is_primary 字段**可先做。

### 班级 tab(2026-06-18 · PM 定:共修 / 讲考 显式分区 + 班级愿 + 我的完成情况)
- **范围口径**:班级 = 一切挂本班(`cohort`)的内容 **+ 我在本班的修学完成情况(本人自视)**。**共修 / 讲考 / 班级愿是班级专属**(`group_sessions` / `speaking_sessions` 均 `cohort_id NOT NULL`;班级愿 = `user_practice_vows` `source='auto'` + 本 cohort)→ 必在班级模块展示;**平台法会 / 发愿 / 法会集体回向(跨班)走首页「活动」卡 → `/activities`**,班级页不重复法会本体。
- **六个分区**:
  1. **本班信息**:专业 · 届 · 辅导员(主麦/爱心);多班 → 主班切换(`switch_primary_cohort`,本人/admin)。
  2. **本周课程**(决策147·PM 2026-06-19):本周计划学习的【**具体课时**】(哪几课 = 班级日历 syllabus,源 `get_current_week_lessons`:program_weeks → program_week_courses → course_lessons)+ **我已学 a/b**(`weekly_study_summary`)。**班级 = 本周计划(学什么)、闻思 tab = 学它们(听/看/答·圆满)**,互补不重复。
  3. **班级愿**:入班按班级模板自动建的 `user_practice_vows`(`source='auto'` + 本 cohort,如 净土「南无阿弥陀佛 5000/天」);**项目/总数/周期锁定、节奏可调**(决策064/术语表)。每条显**本人进度**:频率制愿(daily/weekly,无固定总量)= 日/周节奏 + 已积累 + 今日✅/本周X天;有终点愿(until_complete,如内加行)= **本人总目标 + 累计 + 进度(本人可见·决策014/145)**。**去**状态色(`current_status` 仅管理者可见·检查014)、**去**他人累计(#193);措辞中性、不催促。
  4. **共修**:本班排课(`group_sessions`·挂权威节 `lesson_id`·`cosession_type` regular/practice·`scheduled_at`/`session_end_at`);**我的出勤只「展示」**(`group_attend`/`group_absent`)——出勤**主麦/admin 后台录入、师兄不自报**(决策094/135),班级页不放自助签到。
  5. **讲考**:本班讲考场次(`speaking_sessions`·挂权威节·`session_end_at` 截止);**我的讲考记录** = 主讲/提问/观摩三选一互斥(`speaking_present`/`speaking_question`/`speaking_observe`);讲考=升学人工参考、不自动计分(决策017/101)。
  6. **班级集体动态**:只出**集体总和·不具名·不排名**(如「本周共修 X 万遍」);**去**觉学的班级排行 + 具名随喜(红线 #193)。
- **「用户自己的完成情况」= 各区的「我的」面**:班级愿(我的进度)+ 共修(我的出勤)+ 讲考(我的讲考记录)+ 本班(我的本周学修);均本人自视、克制(无状态色、不催促、**本人可见总目标·决策145**)。
- **无需改 DB**:`group_sessions` / `speaking_sessions` / `study_records` / `user_practice_vows`(source/current_count)/ `weekly_study_summary` 已在基线。
- **⚠️ 待 PM 确认的 IA 重叠**:`/activities` 旧占位文案含「即将共修 · 讲考」,与班级页重复。建议 **活动 = 平台法会 + 发愿/回向(跨班)**、**班级 = 共修/讲考(本班权威视图)**;是否在活动页另留「近期共修」便捷流(=班级 + 活动都出)由 PM 定,默认不在活动页重复班级内容。

### 闻思 tab(2026-06-19 · 采觉学 能力3/37/39 骨架 · 学修中枢)
- **定位**:闻思 tab = **学修中枢**(看/学课程本体);与首页「闻思」卡(快捷继续)互补。内容随**当前主修上下文**(决策144):班级模式=主班本周课;纯自学者本 tab 退居、自学走第 5 tab「自学」。
- **结构**:
